# Sowmya Solar System Portfolio V5

## What changed
- First 3.2s opening is **only a quiet starry night + multilingual greeting**. No moon or solar-system objects in the intro.
- After the intro, the portfolio opens inside a continuous solar-system world.
- A large realistic-looking **moon sits on the right side of the hero** and a soft moonlight beam visually grazes the right side of the real portrait.
- Real uploaded portrait stays in the center of the hero.
- Dark and Day modes use different surfaces/contrast so text remains readable.
- Education animation: B.Tech card enters from the left and IIT Madras card enters from the right.
- Each main section has a different motion language: constellation pop, satellite orbit/reveal, project split, education slide, experience flight, certificate rise, achievement meteors and contact beacon.
- Certificates remain a dedicated proof archive with actual supplied images/PDFs.
- No AI guide/chatbot panel is included.

## Run
```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Important
Open the project through Vite; do not double-click `index.html`.
